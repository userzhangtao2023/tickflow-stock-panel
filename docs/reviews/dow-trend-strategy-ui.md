日期：2026-07-24

从 `REQ-DOW-TREND-STRATEGY-UI-001` 反向核对：

- 策略入口只显示手工执行控制区，不通过挂载副作用启动扫描。
- `dow_trend.py` 位于引擎实际扫描的 `builtin` 目录，`StrategyEngine.get()`、策略列表和策略详情均指向同一 `StrategyDef`；`strategy.py` 已移除静态追加分支，因此不会再出现“列表看似存在、引擎实际不存在”的伪注册。
