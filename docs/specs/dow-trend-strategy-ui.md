# 道氏趋势策略入口

权威需求：

- `REQ-DOW-TREND-STRATEGY-UI-001`：系统必须把 `dow_trend` 作为股票内置策略展示在策略池和策略入口区域。点击策略入口只打开当前市场的手工执行控制区，不得自动启动扫描；只有用户手工点击“执行选股”后，才允许启动当前市场的 5 分钟、15 分钟、30 分钟、60 分钟和日线异步选股任务。任务必须持续展示逐标的进度，不能误走普通 enriched 日线策略执行路径；完成后必须明确展示命中数量或空结果，不能无反馈。

  “内置策略” MUST 表示 `dow_trend` 由 `StrategyEngine` 从 `backend/app/strategy/builtin/` 正式加载，且策略详情、策略池和来源标识都使用同一注册项。接口层 MUST NOT 通过临时追加静态元数据伪造内置策略。由于扫描由专用多周期服务执行，该注册项 MUST 明确标记为 `external`，普通 enriched 策略批量执行路径不得执行它。

  道氏策略命中的股票 MUST 转换为系统统一的筛选结果行，并复用现有 `ScreenerTable` / `StockDataTable` 列表框架展示。列表必须继续提供现有的排序、筛选、列配置、批量加入自选和股票详情入口。道氏结果 MUST NOT 再以横向滚动的逐股票卡片展示。切换市场或重新执行时必须清空上一批道氏结果，不得自动执行新市场扫描。

## 权威变更

- 2026-07-24 用户决定：废止道氏命中股票的独立候选卡片展示，统一使用系统已有股票列表框架。
- 2026-07-24 用户决定：道氏多周期能力必须成为策略引擎正式加载的内置策略，不接受接口或页面临时拼接。
