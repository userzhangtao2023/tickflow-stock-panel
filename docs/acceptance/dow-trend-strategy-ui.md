# 道氏趋势策略入口验收

状态：通过（2026-07-22）。

- `dow_trend` 由 `/api/strategies` 作为股票内置策略返回，名称为“道氏趋势 · 多周期”。
- 首次加载时自动加入当前策略池，策略卡片与其他内置策略并列展示。
- 点击卡片只打开专用三市场、多周期选股/回测面板；自动批量扫描显式排除该 ID，不调用普通 enriched 日线策略执行接口。
- 打开专用面板时自动启动当前市场的异步选股任务；切换市场会清除上一市场结果并启动新市场任务，不会一次扫描三个市场。
- 运行中持续显示已完成数量、总数和当前股票；同市场重复点击复用运行中任务，完成后加载最新物化选股池。
- 加载后明确展示市场、完成状态和命中数量；空池显示“当前暂无符合条件的股票”，并保留手动刷新能力。
- 注册契约测试、专用面板自动加载及手动刷新行为测试和前端生产构建均通过。
